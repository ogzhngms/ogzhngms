**[SorGez](https://github.com/ogzhngms/sorgez-android) — an AI trip planner (open source)**

Six short questions become a Gemini prompt, and the day-by-day plan comes back as JSON held to a closed schema. When a model is overloaded, out of quota or too slow, the request moves quietly down eight free Gemini and Gemma models. Tested against a local fake of the Gemini API, with Compose UI tests and CI on every push.
